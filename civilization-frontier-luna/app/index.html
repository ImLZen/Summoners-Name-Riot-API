Civilization Frontier: Luna

Construye una red lunar que pueda sobrevivir; corta o protege las líneas que mantienen vivas las colonias.

Multijugador privado (2–16)

Cómo se juega

  1. Elige un punto de alunizaje: verás seguridad, recursos y rivales aproximados.
  2. Construye generador y nodo de oxígeno, y conéctalos al hábitat antes de agotar las reservas.
  3. Explora con el rover, expande territorio y extrae minerales y hielo.
  4. Las redes se cortan: protege las tuyas, sabotea las enemigas.
  5. Gana manteniendo el control estratégico. Si caes pronto, puedes realunizar una vez.
