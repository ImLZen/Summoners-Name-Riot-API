# ADR 0006 — Dirección visual 2D producible

- Estado: Aceptada
- Fecha: 2026-07-22

## Decisión

La estética aprobada se implementará con mapa 2D, sprites prerenderizados, overlays y UI web. No se usará 3D en tiempo real en v0.01.

Los hexágonos de los mockups son una convención visual y no fuerzan un cambio del modelo territorial.

## Consecuencias

- Menor coste de arte e ingeniería.
- Mayor compatibilidad con OpenFront y navegador.
- Necesidad de reglas estrictas de zoom, densidad y silueta.
