# ADR 0005 — Cuatro recursos lunares

- Estado: Aceptada
- Fecha: 2026-07-22
- Sustituye: ADR 0002 para el MVP lunar

## Decisión

La economía v0.01 usa Energía, Oxígeno, Minerales y Agua/Hielo.

## Razón

Cada recurso tiene una función visible y temática: funcionamiento, supervivencia, construcción y expansión polar. Cuatro es el máximo admitido en la barra principal del MVP.
