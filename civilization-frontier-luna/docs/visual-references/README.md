# Referencias visuales aprobadas

Estas imágenes están aprobadas como **dirección visual producible**. No son capturas de juego ni especificaciones pixel-perfect.

## 01-production-style-guide.png

Fuente principal para paleta, familias de sprites, rutas, territorio, iconos y densidad. Todo debe traducirse a sprites 2D y UI real.

## 02-main-menu.png

Referencia para jerarquía del menú y presentación del mapa. Se excluyen nivel, XP y progreso persistente.

## 03-early-game.png

Referencia para el primer minuto, fog, objetivos y lectura de estructuras. El texto “turno” debe sustituirse por tiempo real.

## 04-mid-late-game.png

Referencia de densidad máxima, rutas y facciones. La versión real agregará iconos al alejar zoom y reducirá ruido.

## 05-match-timeline.png

Referencia de ritmo de partida y milestones. No es una pantalla obligatoria.

## Reglas transversales

- 2D runtime.
- Sin cámara 3D.
- Sin funciones persistentes salvo aprobación futura.
- Hexágonos opcionales como overlay.
- Recursos y rutas siempre reconocibles por forma, icono y patrón.
